# العاقل ماركت - تطبيق المتجر الإلكتروني (Flask)

تطبيق متجر إلكتروني متكامل مبني باستخدام إطار العمل **Flask** بأسلوب وشكل متوافق مع تصميم الجوال الحديث، مقتبس ومطور من تطبيق Flet (`mine.py`).

## 🚀 المميزات
- **تصميم عربي كامل (RTL)** متناسق وأنيق بنفس الألوان والرموز الأصلية.
- **تصفح الأقسام والمنتجات والعروض** مع دعم البحث المباشر.
- **شريط إعلانات متحرك (Hero Carousel)** يعرض أهم المنتجات المميزة تلقائياً.
- **سلة شراء تفاعلية** لحساب الإجمالي والتحكم بالكميات.
- **نظام الدفع الإلكتروني بالمحافظ اليمنية**:
  - ون كاش (OneCash)
  - جيب (Jeeb)
  - فلوسك (Floosak)
  - الدفع نقدًا عند الاستلام (COD)
- **إرفاق إشعار السداد أو رقم الحوالة** وحفظ بيانات المستلم (`فاضل الزيلة - 773053886`).
- **التحقق من البيانات اليمنية**: الاسم ورقم الجوال اليمني 9 أرقام تبدأ بـ (`77`, `78`, `73`, `71`, `70`).
- **تأكيد الفاتورة المباشر وتصديرها عبر واتساب**.

## 🛠️ كيفية التشغيل

1. **تثبيت المتطلبات**:
   ```bash
   pip install -r requirements.txt
   ```

2. **تشغيل الخادم**:
   ```bash
   python app.py
   ```

3. **فتح التطبيق في المتصفح**:
   افتح الرابط: `http://127.0.0.1:5000`
