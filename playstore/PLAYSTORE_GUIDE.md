# دليل نشر تطبيق «العاقل ماركت» على متجر جوجل بلاي (Google Play Store Guide)

تم إعداد المشروع بالكامل وفق معايير **Trusted Web Activity (TWA)** المدعومة رسمياً من شركة Google لنشر تطبيقات الويب التقدمية (PWA) على متجر Google Play.

---

## 📁 محتويات مجلد Play Store والملفات المجهزة:

1. **`twa-manifest.json`**: ملف ضبط حزمة أندرويد (Bubblewrap Manifest) متضمناً اسم الحزمة `com.alaaqilmarket.app` والألوان والأيقونات.
2. **`playstore-icon-512.png`**: أيقونة المتجر الرسمية بأعلى دقة 512×512 (RGB بدون شفافية) المطلوبة لمتجر Google Play Console.
3. **`../static/manifest.json`**: ملف بيان تطبيق الويب (Web App Manifest).
4. **`../static/sw.js`**: خادم الخدمة (Service Worker) للتخزين المؤقت والعمل دون اتصال وسرعة التحميل.
5. **`../static/.well-known/assetlinks.json`**: ملف التحقق الأمني الرقمي للربط بين النطاق وحزمة التطبيق لإخفاء شريط المتصفح وجعل التطبيق يبدو كتطبيق أندرويد أصلي (Full Native Screen).

---

## 🚀 الطريقة الأولى: إنشاء حزمة أندرويد (.aab / .apk) عبر Bubblewrap CLI (أداة جوجل الرسمية)

Bubblewrap هي الأداة الرسمية المطورة من فريق Google Chrome لنشر تطبيقات الويب إلى Google Play.

### الخطوات:
1. تأكد من توفر Node.js و Java JDK على جهازك.
2. افتح موجه الأوامر (Terminal) ونفذ الأمر التالي لتهيئة وبناء الحزمة:
   ```bash
   # تثبيت أداة Bubblewrap
   npm install -g @bubblewrap/cli

   # داخل مجلد playstore قم بالبناء:
   cd playstore
   bubblewrap build
   ```
3. ستطلب الأداة منك كلمة مرور لمفتاح التوقيع الرقمي (`android.keystore`).
4. بعد اكتمال البناء، ستجد ملف الحزمة بصيغة **`app-release-bundle.aab`** جاهزاً للرفع مباشرة على Google Play Console!

---

## ⚡ الطريقة الثانية: عبر PWABuilder (أسرع وأسهل طريقة بدون تثبيت أدوات)

إذا كنت لا ترغب بتثبيت Java أو أندرويد SDK:
1. ارفع موقعك على النطاق الخاص بك (مثل `https://your-domain.com`).
2. توجه إلى موقع: **[PWABuilder.com](https://www.pwabuilder.com/)**.
3. ضع رابط موقعك واضغط **Start**.
4. سيتحقق الموقع من معايير PWA (جميعها أصبحت 100% مكتملة وجاهزة).
5. اضغط على **"Package For Stores"** واختر **Google Play (Android)**.
6. ستحصل على ملف **`.zip`** يحتوي على:
   - ملف **`.aab`** جاهز للرفع على متجر جوجل بلاي.
   - ملف **`assetlinks.json`** لتقوم بنسخه في `static/.well-known/assetlinks.json`.

## 🔐 ضبط التحقق الأمني (Digital Asset Links):
للتأكد من أن التطبيق يعمل بملء الشاشة دون ظهور شريط عنوان المتصفح:
1. عند إنشاء مفتاح التوقيع (Keystore)، استخرج بصمة SHA-256 الخاصة به عبر الأمر:
   ```bash
   keytool -list -v -keystore android.keystore -alias alaaqil_market
   ```
2. انسخ بصمة `SHA256 Fingerprint` وضعها في الملف:
   `static/.well-known/assetlinks.json`
3. تأكد أن موقعك يعمل ببروتوكول **HTTPS** عند رفعه على الاستضافة.
